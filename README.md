# Alex Morgan Portfolio

A semantic HTML-only portfolio page created for the HTML Project 1 checkpoint.

## Included

- A navigation bar linking to Home, About, Work, Resume, and Contact.
- Semantic sections for the profile, selected work, resume, and contact form.
- A project table, unordered list, definition list, and local in-page links.
- An image, HTML5 video, and HTML5 audio controls.
- A contact form with name, email, project type, message, submit, and reset controls.
- A page footer with a back-to-top link.
- HTML comments explaining the main page regions.

## Open the page

Open `index.html` directly in a browser. No CSS, JavaScript, build tools, or installation are required.

The image, video, and audio use remote sources, so an internet connection may be needed to display or play them.
