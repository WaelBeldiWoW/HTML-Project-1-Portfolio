# Wael Beldi Portfolio

A semantic HTML-only portfolio page for Wael Beldi, a Fullstack JavaScript instructor. This project was created for the HTML Project 1 checkpoint.

## Included

- A navigation bar linking to Home, About, Work, Resume, and Contact.
- Semantic sections for the profile, teaching work, professional profile, and contact form.
- Semantic HTML layout without tables or CSS.
- Local profile picture, workspace video, student-session picture, and resume PDF.
- HTML5 video and audio controls.
- A contact form with name, email, project type, message, submit, and reset controls.
- Unordered and definition lists, local in-page links, figures, and captions.
- A page footer with a back-to-top link.
- HTML comments explaining the main page regions.

## Local assets

- `assets/profile.jpg` - Wael Beldi's profile picture.
- `assets/Nabeul Hackerspace.mp4` - Workspace video.
- `assets/Nabeul Hackerspace.png` - Teaching session with students.
- `assets/CV_Wael_Beldi.pdf` - Downloadable resume.

## Open the page

Open `index.html` directly in a browser. No CSS, JavaScript, build tools, or installation are required.

The local image, video, and resume work without an internet connection. The audio player uses a remote source and may require an internet connection.
